## 核心能力
- **68 个专用 Agent**：规划、审查、构建修复、安全、架构等
- **286+ 可复用 Skill** + 94 命令 shim + 选择性规则包
- Runtime hooks 强制执行 + instincts 持续学习
- AgentShield 安全扫描
- 统一工作流：plan → test → implement → review → verify → remember → improve（TDD RED-GREEN-REFACTOR 门禁证据）
- fresh-context code review、build repair、session persistence、Plan Canvas

把 AI 写代码当日常、但被"每次开会话像换了个实习生"困扰的团队/个人——一致性是最贵的隐性成本。
