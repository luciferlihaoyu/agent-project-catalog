## 一句话描述

Agent 工作流的「批注决策台」—— 不执行、不代替 agent，而是横在"agent 提方案"与"agent 动手"之间：shape / decide / plan / annotate / review，最后一键把全部反馈发回 agent。

## 为什么值得关注

- 定位独特：不是又一个 harness 或 IDE，而是「人在环」的监督层，补齐 agent 生态中"人拿回决定权"的缺口。
- 跨 harness 通用：Topics 同时覆盖 claude-code / codex / opencode / pi-mono，与 JetBrains thinkrail（运行时宿主）、paperclip（团队管理台）互补。
- 一年不到破万星、今日仍稳态 +108，208 open issues 对体量来说干净，商业公司做派（官网 + Apache-2.0）。
