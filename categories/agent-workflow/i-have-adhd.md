# i-have-adhd

> 仓库：https://github.com/ayghri/i-have-adhd · ⭐ 55,138（2026-10-08 API 实测） · License: MIT

**一句话：** 强制 AI 编程助手先说答案、别埋结论——废话直接砍掉。

## 核心能力
- 回复强制结构：第一行"接下来做什么" → ≤5 条编号步骤 → 最后一行"你的第一个动作"
- 去掉所有开场白、总结语、客套话（原本 100 词寒暄 → 3 行可执行指令）
- 分钟级时间估计 + 每轮重述当前状态
- 7 种语言规则版本（英/中/日/韩/越/泰/葡）
- 零配置，装上即生效（AGENTS.md / skill 文件集成）

## 适用场景
用 Claude Code / Codex / Cursor 等 Agent 觉得回复啰嗦埋答案的开发者。

## 备注
规则文件可在 `skills/i-have-adhd/SKILL.md` 自定义。
