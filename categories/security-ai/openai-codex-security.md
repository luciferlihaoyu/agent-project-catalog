## 为什么值得关注
- 安全扫描从「规则匹配」走向「agent 验证」：Codex Security 强调的不只是**找**，还有**validate（证明可利用）与 fix（给出补丁）**，能把误报压下来
- 有官方 CLI 与 SDK 两条接入路径，CI 里一行命令、或自己写脚本批量扫都可以
- Apache-2.0 + 官方文档站，商业项目接入无协议顾虑；与 Cloudflare security-audit-skill、NVIDIA SkillSpector 构成「agent 安全工具链」三件套
