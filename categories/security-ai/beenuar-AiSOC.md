## 一句话描述

**开源 AI 安全运营中心（SOC）** —— 告警融合 + LLM-agent 分诊 + MITRE ATT&CK 调查 + 每步可回放的决策台账，自托管、零 API key、LangGraph 驱动、自带 MCP server。

## 备注

把 SOC 蓝队分诊做成 agent 流水线，「replayable decision ledger（决策全程可回放可审计）」是核心卖点——与 CopilotKit/OpenBot 同日 trending，印证「可审计」从合规要求变成产品特性。与 pentagi（进攻性）、NVIDIA/SkillSpector（skill 扫描）构成 security-ai 分类里的蓝队新成员。⚠️ 仅 14 open issues、6 个月 6.2 千星，增速快，安全结论可靠性需实践检验。
