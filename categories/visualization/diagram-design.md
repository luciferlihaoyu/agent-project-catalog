## 一句话
给 agent 用的「编辑部级」图表设计技能：**42 种图表类型**，自包含 HTML + SVG，明确拒绝 Mermaid 流俗。

## 核心能力
- 42 种图表类型，编辑级平面设计风格（**无阴影**、克制配色）
- **零依赖单文件输出**：产出 HTML + 内联 SVG，随取随用
- 多 agent 平台适配：Claude Code / Codex / GitHub Copilot / Factory Droid / Pi

## 适用场景
- 技术文档、架构图、汇报图表产出
- 需嵌入现有报表流程（单文件零依赖，直接塞进 pipeline）

## 备注
- 与 `archify`（可验证架构图）、`God's Eye View`（3D 可视化）同属可视化方向，但更偏"文档级图表"产出
