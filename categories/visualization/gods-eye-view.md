# God's Eye View

> 仓库：https://github.com/bilawalsidhu/gods-eye-view · ⭐ 41.4K（2026-09-23 API 实测） · JavaScript · License: 自定义（NOASSERTION）

**一句话：** 浏览器里的"间谍卫星模拟器"——数据全是真的。实时公开信号叠加在写实 3D 地球仪上。

## 核心能力
- ✈️ 实时航班 ADS-B 追踪（含驾驶舱视角，贴着地形下降）
- 🚢 船舶 AIS 定位
- 🛰️ 卫星轨道 + 过境预测
- 🌊 地震、交通、公共摄像图层
- 🎙️ 语音控制 + 语音白板（说出边界/航线直接画到地球上）
- GLSL 传感器外观：CRT / 夜视 / 热成像等重皮肤
- 🔗 分享链接：相机/图层/追踪目标序列化进 URL
- ⚡ 无需 API Key 即可启动（Cesium ion / Google Maps 为可选增强）

## 适用场景
数据可视化 Demo、OSINT 轨迹研究、地理信息系统参考实现、演示装逼。
