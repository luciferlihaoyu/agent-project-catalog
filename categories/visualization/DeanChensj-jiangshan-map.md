# DeanChensj/jiangshan-map

> 仓库：https://github.com/DeanChensj/jiangshan-map · ⭐ 6,720（2026-11-17 API 实测） · JavaScript · License: GPL-3.0

**一句话：** 江山时序 · 中国历史交互地图时间轴（403 BCE – Present）—— 覆盖 18 个朝代的 198 张疆域快照，配古今地名谱系与古典诗词地理路线，纯前端可离线跑的数字人文 Atlas。

## 核心能力
- **198 张疆域快照**：从战国（前 403 年）一路到当代，按时间轴连续滑动查看疆域变迁
- **18 个朝代视角**：朝代切换即地图切换，边界、政权、都城同步
- **古今地名谱系**：同一个地名在历代的演变链条（今天叫这个名字，当年叫什么、属哪个州府）
- **古典诗词路线**：把诗词里提到的地点串成地理路径，文本与地图互跳
- **数字人文 / GIS 取向**：topics 里同时有 cartography、gis、chinese-history，不是一张静态图
- **纯静态站**：官方 demo 直接跑在 GitHub Pages 类环境，无须后端

- 历史 / 地理 / 语文教学内容可视化（课堂演示、课件、历史地图对照）

- 数字人文项目参考：历史数据建模 + 时间轴地图交互的完整范例

## 为什么值得关注
- **这是一个有真实工程量的作品，不是 Trending 常见的 demo。** 198 张疆域快照意味着大量史料数字化、配准与边界矢量化工作；三个半月做到 6.7K 星、fork 率 11.8%，说明数字人文社区是真的在拿它改。
- **中文开源里最缺的就是这类"文化基础设施"**：既有严肃的史料骨架，又有可用的交互界面。它比"用 AI 生成历史地图"的项目靠谱得多——数据是有出处的静态资产，不依赖模型幻觉。
- **古今地名谱系这层最有长期价值**：地名是历史研究的硬骨架，做成可查询的谱系表后，可复用到地方志、家谱、文学地理多个方向。
