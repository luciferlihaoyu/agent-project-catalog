## 一句话
An Open Source Machine Learning Framework for Everyone

## 核心能力
- 全面的机器学习库：支持深度学习、传统 ML 等
- TensorFlow 2.x： eager execution 与 Keras 高级 API
- 生成式 AI：集成了Transformer、扩散模型等前沿研究
- 生产就绪：TFX pipeline、TensorRT 部署、SavedModel 格式
- 跨平台：CPU、GPU、TPU 均有优化支持

## 适用场景
- 企业级机器学习项目的标准框架
- 生产环境的模型训练与部署流水线
- 研究原型快速迭代与实验
- 支持 TPU 的大规模分布式训练
