## 一句话描述

**The open alternative to Salesforce, designed for AI.** —— 开源 CRM（Salesforce 替代品）：PostgreSQL + NestJS + React + GraphQL 的 monorepo，把销售线索 / 客户 / 商机 / 营销自动化全部开源，定位是"为 AI 时代重新设计的 CRM"。

## 核心能力

- **完整 CRM 功能**：contacts / companies / opportunities / pipelines / 邮件日历同步 / 营销自动化
- **技术栈现代**：NestJS + React + PostgreSQL + GraphQL + Redis，monorepo 工程规范，good-first-issue 友好
- **AI 原生设计**：不是给旧 CRM 贴个 AI 聊天框，而是围绕 AI agent 可操作的数据模型重构
- **自托管**：企业可完全私有化持有客户数据，SaaS 迁移成本重新变成自己的

## 备注

归类 **backend-platform** —— 与 supabase/supabase 同属"应用后端底座"大类。**关注点**：Salesforce 一家吃掉全球 CRM 巨额利润，SaaS 闭源 + 天价订阅成了 SMB 的痛点。Twenty 用 AGPLv3 + Postgres 起家，是当前最像"能真替换 Salesforce"的开源项目；59K 星、9.6K fork 说明它在自托管圈层已形成实际用户基础。需注意协议是 AGPLv3 主体（部分企业文件带 `@license Enterprise` 标记走商业条款），二开对外提供网络服务需谨慎评估合规。
