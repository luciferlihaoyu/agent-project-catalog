## 一句话描述

**The Postgres development platform.** —— 开源 Postgres 应用开发平台：一套数据库 + 认证（Auth）+ 实时订阅（Realtime）+ 存储（Storage）+ Edge Functions + pgvector 向量检索，一站式构建 Web / 移动 / AI 应用。

## 核心能力

- **Postgres 直上**：完整 SQL、PostGIS、pgvector，不是"阉割版数据库"，没有厂商锁死
- **BaaS 全家桶**：Auth（OAuth2/邮箱/短信）、Realtime（WebSocket）、Storage、Edge Functions（边缘运行时）
- **AI 原生**：pgvector 向量检索 + 内置 embedding，与主流向量库同构但和业务表同库同事务
- **自托管友好**：Apache-2.0，可完全私有化部署，对数据合规敏感的企业是加分项

## 备注

归类 **backend-platform**（本次新建分类）—— 属于"应用后端底座"这一类，而非普通开发工具。**关注点**：它是 Firebase 那一挂的开源解药，三年烧掉数亿美元后 Supabase 用"真 Postgres + 开源协议"打赢了这条路。113K 星 + 每天仍稳定 +500 说明它已经是新项目的默认起点之一；Apache-2.0 协议对商业友好度远高于同类 Firebase 闭源条款。
