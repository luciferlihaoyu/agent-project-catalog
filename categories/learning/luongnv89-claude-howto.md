**一句话：** Claude Code 视觉化实战指南 —— 从基础概念到高级 Agent，全部配可复制的模板，照抄即用。

## 核心能力
- **图解优先**：每个概念配架构图/流程图，而非纯文字 —— 面向"看图比读文档快"的开发者
- **由浅入深**：基础概念 → 实战技巧 → 高级 Agent（多 Agent 协作、MCP、Hooks 等）
- **Copy-Paste 模板**：README 直接给可复制粘贴的配置/命令/CLAUDE.md 片段，省掉"我知道要用但不知道长什么样"的空转
- **实战导向**：偏任务驱动（怎么用 Claude Code 干具体活），而非 API 文档式罗列
- **多语言文档**：含中文/英文版本
- **在线预览**：http://luongnv.com/claude-howto/

## 适用场景
- Claude Code 新手快速上手（1 小时建立完整心智模型）
- 想要一份可速查的 CLAUDE.md / settings.json / 钩子配置模板库
- 团队内部分享 Claude Code 实践的培训материал
- 排查"Claude Code 为什么不按我说的做"——对照高级章节的提示词技巧

## 为什么值得关注
- **43K 星 / 5.3K fork：fork 率 12.5%**。这个数字在"教程类"仓库里极不寻常 —— 说明大量人不是读过就忘，而是 **clone 下来放进自己的项目当模板库**。这才是它能持续涨星的关键。
- **它把"文档"变成了"资产"**：Claude Code 的官方文档偏 API 参考，而真正需要的是"我该怎么用它干活"的经验。这份指南正好补上这一层，视觉化 + 可复制模板的组合让它成为中文圈的默认参考。
- **与 agent-skills 生态的分野**：仓库里的 `learning/` 分类（system-design-notes、lingbot-map）走的是"体系化知识"路线，而本仓库走"视觉速查"路线，两种补法并存。
