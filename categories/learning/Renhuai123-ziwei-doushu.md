# Renhuai123/ziwei-doushu

> 仓库：https://github.com/Renhuai123/ziwei-doushu · ⭐ 6,858（2026-10-24 API 实测） · TypeScript · License: MIT（代码）/ CC BY 4.0（数据集）

**一句话：** 紫微斗数开源排盘引擎 —— 基于倪海厦《天纪》教学体系，含完整排盘算法、四化系统、格局知识库、古籍原文数据，以及一套规模惊人的解读数据集。

## 核心能力
- **完整排盘引擎**：12 主星 / 14 辅星 / 四化系统 / 12 宫位 / 大限流年，含真太阳时校正（中国夏令时 `chinaDSTSpan`）、省市县与新疆兵团经纬度
- **13 维解读数据集 v4.0**（2026-10-15 发布）：674,976 张命盘（1950–2026 每真实日期 × 12 时辰 × 男女）× 13 维 = **8,774,688 段解读**，正文约 204 亿字，解压后 56.6 GB（压缩包仅 161 MB，按年份分 77 个文件）
- **断语逐句校正**：每条引文都能在《紫微斗数全书》原文逐字核对，标着倪师却查不到出处的直接删除；不会发生的四化（七杀化权、紫微化忌）相关断语移除
- **古籍引证 405 处**：知识库每处引证都能在《紫微斗数全书》原文逐字找到
- **倪师《天纪·紫微斗数》原话库**：14 讲 + 2 段补充、1848 条，逐条标注集数与时间码可回放
- **在线体验**：metisziwei.com 排盘 / AI 解读 / 命盘历史全开放
- **星曜亮度默认改为《斗数全书》**（2026-10-20），与主流排盘软件一致

## 为什么值得关注
- **把「玄学」做成了可验证的工程**。这是我今天最想标出来的一点：它的断语校正规则是「标了来源却查不到出处的就删」「不会发生的四化不写」——这是**可审计的知识工程**，不是生成式幻觉。它甚至公开了「六亲判断有局限，倪师自己说『斗数批六亲本来就比较差一点』」并给出铁板神数的替代建议。**敢于在自家 README 里写自己体系短板的垂直项目，可信度会高一个档次。**
- **6 个 open issue 配 6,858 星**，是本期所有项目里最干净的维护信号，说明 issue 区真的在被经营。数据集迭代节奏也稳（v3.0 → v4.0，30% 命盘量、71% 体积增长，且逐文件解压做字节级比对后才发布）。
- **数据规模是硬护城河**：204 亿字、877 万段结构化解读、56.6 GB —— 这个量级的垂直领域中文语料，在中文 AI 数据稀缺的背景下是稀缺资产（且 CC BY 4.0 可商用，代码 MIT）。
- ⚠️ 关注理由：解读正文引用倪师原话的部分**不在数据授权范围内**（CC BY-NC-SA 4.0，非商用），商用前必须分开审阅代码 / 数据集 / 原话引用三层许可，这是最容易踩的坑。
