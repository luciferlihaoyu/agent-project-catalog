## 核心能力 / 内容结构

- **开篇即方法论**：README 顶部是一段可读的 Python 伪代码 —— `def teach_yourself(anything): while not create(): learn(); practice()`，递归到 `teach_yourself(coding)`。**学习即实践、实践即学习，直到能「造」。**
- **Part 1 基础篇**：为什么一定要掌握自学能力 / 为什么把编程当自学的入口 / 只靠阅读习得新技能 / 阅读前的准备 / 入口 / 值及其运算 / 流程控制 / 函数 / 字符串 / 数据容器 / 文件 / 如何从容应对「过早引用」的知识 / Python 官方教程本地版。
- **Part 2 进阶篇**：笨拙与耐心 / 刻意练习 / 为什么从写函数开始 / 参数（上下）/ …… 后续含面向对象、函数式、调试、测试、Git 与协作等章节。
- **Jupyter Notebook 为第一公民**：每章一个 `.ipynb`，可本地跑 JupyterLab 边读边执行；另提供 markdown 版本分支。
- **proof-of-work 校对流程**：README 单独开一节说明「如何用 Pull Request 为这本书校对」—— 2019 年的开源协作范式。

## 为什么值得关注

- **fork 率 96.7%（17,886 / 18,501）是全库最极端的指标** —— 几乎每个 fork 就是一份个人副本。这在「学习型仓库」里几乎独一份：**它不是被 clone 下来跑的，是被「抄走当自己的教材」**。对比同为学习类的 `xiaoyang111222/cn-math-taxonomy`（工具型，可运行）—— **这一本是一次性阅读物，fork 即复制**。
- **它同时是最早和最不像 2026 年产物的中文编程读物**：2019 年立项，用今天的标准看依然没有过时 —— 「笨拙与耐心」「刻意练习」「只靠阅读习得」这几章，**把「学不会」归因到方法而不是天赋**，这在 AI 辅助编程的当下反而更值钱。
- **中英双语的稀缺性**：README 的英文引言「One has no future if one couldn't teach themself」是中文语料里少见的、能直接被全球引用的一句。
- **它的今日热度是「再度出圈」而非「持续开发」**：最后推送 2026-05-20，但今天仍 +148 —— **说明 GitHub 有一个真实的「经典中文教程被重新发现」的需求**，这类项目平时不动，一被推上 Trending 就能吃到跨圈层流量。

## ⚠️ 局限

- **协议未标注** —— GitHub API 无 license 字段，**默认版权保留，不构成开源授权**，转载/再分发需谨慎（虽然作者本人公开鼓励 fork）。
- **纯阅读物，无法「跑出成果」**：与 `HKUDS/DeepTutor`（agent 原生学习工作台，可交互可检视）不同，这本书给你的是**方法论而非工具链** —— 对已有基础者是复盘，对零基础者仍需另配学习环境。
- **2019 年的 Python 语境**：环境与库版本已明显演进，示例部分需自行适配。
