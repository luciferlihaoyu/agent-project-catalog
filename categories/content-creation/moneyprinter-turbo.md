# MoneyPrinterTurbo（钞票打印机）

> 仓库：https://github.com/harry0703/MoneyPrinterTurbo · ⭐ 125.2K（2026-09-23 GitHub API 实测；L 资料为 109K） · Python · License: MIT · Forks 19.4K · 2024-03 立项，2026-09-21 仍在更新

**一句话：** 给一个主题，全自动产出一条 1080P 高清短视频——脚本、素材、配音、字幕、BGM 一条龙，最快一分钟出片。

## 核心能力
- ✍️ LLM 自动写视频脚本（需自备大模型 API key：DeepSeek / Kimi / 通义等均可）
- 🎞️ 自动从免费素材库匹配高清画面
- 🎙️ AI 配音 + 自动字幕 + 背景音乐
- 🎬 合成 1080P 成片；支持批量生成、择优发布
- 🌍 多语言脚本，面向 TikTok / Instagram Reels / YouTube Shorts 海外内容

## 适用场景
- 知识类短视频试水：一句话先出片看效果，再决定是否认真做
- 批量测试选题：一次生成多条，挑最满意的发
- 海外内容矩阵：多语言 + 多平台分发

## ⚠️ 局限
- 需要自备大模型 API key
- 产出偏模板化流水线风格，不适合动画 / 影视级创作
