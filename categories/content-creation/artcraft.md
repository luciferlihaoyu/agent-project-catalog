# storytold/artcraft

> 仓库：https://github.com/storytold/artcraft · ⭐ 7,937（2026-10-08 API 实测） · License: NOASSERTION（自定义，非标准 SPDX） · 官网：https://getartcraft.com/ · 语言：Rust

**一句话：** "艺术家的 IDE"——在 2D 里构图、在 3D 里布景，先搭好画面再让 AI 生成，把 prompt 变成可控的"crafting"。

## 为什么值得关注
- **今日增速全场第一（+2,103）**，单日涨了约 26% 的星标，是本轮唯一"翻倍级"爆发项目。
- **反 prompt 潮流**：不让用户盲抽文字提示，而是给构图、角色一致性、机位摆放的**可视化精确控制**，命中 AI 图像/视频生成最大的痛点（不可复现）。
- **Rust 桌面应用**：本地跑的创作工具，不是网页玩具，适合纳入严肃制作流程。
- 附带完整社区运营（Discord / YouTube / X / LinkedIn），商业化路径已铺开。

## 核心能力
- 2D 构图 + 3D 场景搭建，生成前先定死画面结构
- 多模型可选，按作品挑合适的生成模型
- 角色身份一致性、镜头机位等高级 crafting 功能（官方附演示视频）

## 适用场景
- 概念设计、分镜、影视/动画前期视觉预演
- 需要"可复现、可迭代"的 AI 图像/视频工作流
