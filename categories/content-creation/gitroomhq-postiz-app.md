## 一句话
开源版社交媒体排期工具——Next.js + Redis，支持多平台排期 / 自动化 / 数据分析，可自托管或用 Postiz Cloud；开放 Public API、NodeJS SDK、n8n 节点与 Make.com 集成。

## 核心能力
- **多平台排期**：一个后台管理全部社交账号的发布计划
- **Open API 优先**：Public API + `@postiz/node` SDK + `n8n-nodes-postiz` + Make.com app——**这是它被标为 agentic 的真正原因：Agent 可以直接调它**
- **两种形态**：Postiz Cloud（全托管）或自建开源版（数据自持）
- 技术栈：Next.js + Redis

## 为什么值得关注
- **2023 年立项，三年后仍 +188/日、3.8 万星**——老项目靠「agentic 化」找到第二增长曲线的典型样本：赛道没换，只是把老产品重新包装成 Agent 可调用的 API。
- **fork 率 19.4% 偏高**，说明大量用户选择自托管而非用 Cloud——这正是 AGPL + 自托管路线的典型用户画像。
- 交付物是「已排期的内容」，不是建议——符合 2026 年「AI 要能交付可直接使用的东西」的价值锚点。

## ⚠️ 局限
