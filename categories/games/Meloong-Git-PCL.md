**一句话：** Plain Craft Launcher（PCL）—— 中文 Minecraft 启动器，一键导入整合包、自动装模组/光影/版本。

## 核心能力
- **版本管理**：自动下载/切换 Minecraft 正式版、快照版、Modrinth 整合包，一次点击搞定
- **模组与光影**：内置 Modrinth / CurseForge 源，批量安装与依赖自动解析
- **整合包一键导入**：粘贴整合包链接 → 自动拉取全部文件 + 依赖 + 资源包
- **离线/内网下载加速**：多线程下载器 + 镜像源切换，国内网络友好
- **自动安装 Java**：按版本需求自动匹配并安装合适的 JRE
- **轻量启动**：Visual Basic .NET (WinForms) 编写，内存占用远低于 Java 生态的启动器
- **中文本地化**：界面、报错、教程全中文，面向国内玩家
