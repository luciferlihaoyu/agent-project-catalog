## 一句话
**用最贵的模型做审计，用便宜的模型做执行**——把「代码库体检」和「按计划改码」拆成两档成本。

## 关键数据
- 6 个月 1.09 万星、fork 率仅 4.1%，是「收藏多于自改」的典型工具型项目
- open issues 只有 18 条，问题面很干净
- ⚠️ 最后推送 2026-09-12，两个月没动，热度靠社区扩散而非持续开发

## 为什么值得关注
- 这是一条**成本工程**思路，而不是又一个 agent 框架：强模型只负责「读-判断-写计划」，弱模型拿计划去改文件，token 账单一刀切两半
- 与 spec-kit、pr-agent 同一生态位，但更聚焦「审计 → 计划 → 廉价执行」这一段流水线
- MIT 协议可以在公司内部直接落地改造；先把计划模板看一遍再决定要不要接自己的 CI
