## 一句话描述

**为 AI agent 设计的 Git** —— 把 AI agent 的代码改动纳入 Git 工作流（attribution / commit / branch 等），让 agent 像人类开发者一样被版本管理。

## 备注

和 wshobson/agents、anomalyco/opencode、anthropics/claude-code 同属 developer-tools 范畴。**关注点**：AI 时代"谁改了这行代码"成为合规/审计问题，git-ai 在 commit message、author 字段之外引入 agent 维度的归属记录，对企业落 agent 必备。
