## 一句话描述

Chrome 官方出品的 DevTools MCP server —— 让 coding agent 直接拿到性能 trace / 网络检查 / console / 页面快照这类「浏览器侧的真相」，而不靠截屏猜。

## 为什么值得关注

- 体量 × 维护健康度今日最夸张：5.5 万星、仅 116 open issues、最后推送前一天，Google 官方把「给 agent 用」变成 DevTools 一等公民场景。
- 给整条 agent-browser 赛道定了标准：对比已收录的 vercel-labs/agent-browser（Rust CLI 直调）与 lightpanda/browser（自研引擎），接官方 MCP 比自研协议层划算。
- 做 E2E 自动化、前端 agent 调试、浏览器巡检的工具链，默认应选它做底座。
