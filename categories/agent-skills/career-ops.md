## 一句话
开源 AI 求职流水线：扫职位门户 → 生成结构化 A-H 报告 + 全局 1-5 分评分 → 依岗位定制 CV → 追踪投递，全程本地跑在你的 AI CLI 里。

## 核心能力
- 岗位扫描 / 职位评估（A-H + 评分）/ ATS 优化简历 / 求职信
- 支持 Claude Code、Codex、OpenCode、Antigravity 等

## 适用场景
- 求职季自动化：从"看岗"到"投递追踪"全链路
