# airllm

> 仓库：https://github.com/lyogavin/airllm · ⭐ 36,488（GitHub API 实测） · Jupyter Notebook · License: MIT · 备注：AirLLM 70B inference with single 4GB GPU

**一句话：** 单首 4GB GPU 即可跑 70B 参数模型的推理解决方案。

## 核心能力
- 70B 参数模型在单张 4GB GPU 上的极致推理优化
- 支持多种主流 LLM 推理框架
- 极低显存占用，突破硬件限制的创新方案

## 适用场景
- 资源有限但需要大模型推理的场景
- 边缘设备上的 AI 推理
- 对成本敏感的部署环境
