## 一句话
"给你的 Agent 一双看遍互联网的眼睛"——一个 CLI 零 API 费读/搜 13+ 平台：Twitter/X、Reddit、YouTube、GitHub、B站、小红书等。

## 核心能力
- 跨平台信息抓取与检索统一入口
- 零 API 费用（不走付费 API，走公开通道）

## 适用场景
- Agent 的信息采集层：热点监控、社媒倾听、竞品调研
