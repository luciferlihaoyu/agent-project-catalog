## 一句话
在 agent 里打一句话，拿回能交付的设计：网页 / App 原型 / 可编辑 PPTX / 动画 / 信息图——3 到 30 分钟，3.0 版本是「先出六张缩略图挑三个方向，再做成真稿」。

## 核心能力
- **六候选 → 三方向 → 真稿**：把「先探索、后收敛」的设计工作流固化成 skill，人只在关键分叉点做选择
- **84 种带样张的风格库**（3.0 新增 App、中文、东亚三个分区）——每种风格配样张，解决「风格名对不上效果」的对齐问题
- **品牌资产感知**：喂给它 logo、色板、UI 截图，它读懂品牌气质；不给也能兜底到「不出 AI slop」
- **设计体检只量事实**：不给「你做得不够好」这类主观评价，只给可测量的结论
- **外观账本**：记住你做过什么样子，避免下一个项目长成一个样
- **交付物而非建议**：可编辑 PPTX、可点击 App 原型、动画、信息图
- 跨 agent 通用：Claude Code、Cursor、Codex、OpenClaw、Hermes

## 为什么值得关注
- **今日涨幅全场第一（+251）**，且只有 6 个 open issues——对 2.67 万星来说低得反常。

## ⚠️ 局限
- 仓库主语言是 **HTML 而非 Python/TS**，说明它更像「方法论 + 模板资产」而非代码库——版本迭代护栏比常规软件弱。
