## 一句话
Context window optimization for AI coding agents. Sandboxes tool output (98% reduction), persists session memory, and enforces routing across 17 platforms via MCP + hooks。

## 核心能力
- **沙箱工具输出**：98% 减少，有效缓解上下文膨胀
- **会话记忆持久化**：跨会话保持上下文一致性
- **MCP + hooks 路由**：支持跨 17 个平台的统一调度
- **精准过滤**：只保留相关工具输出，剔除噪声

## 适用场景
- 处理大型代码库的 AI 编程代理
- 长时会话中需要保持上下文连贯性的场景
- 跨多平台（MCP）的代理路由优化
- 减少 Token 成本的上下文管理需求
