# AgriciDaniel/claude-seo

> 仓库：https://github.com/AgriciDaniel/claude-seo · ⭐ 20,863（2026-10-26 API 实测） · Python · License: MIT

**一句话：** 通用 SEO 技能包 —— 26 个子技能 + 19 个子代理，覆盖技术 SEO / E-E-A-T / Schema / GEO·AEO / Agent 就绪度（Lighthouse Agentic Browsing、WebMCP、llms.txt）/ 外链 / 本地 / 跨境电商 / Google APIs / PDF·Excel 报告。

## 核心能力
- **26 子技能 + 19 子代理**：把「SEO 专家的完整工作流」拆成可按需加载的技能与子代理
- **GEO / AEO 是差异化重点**：面向 AI 搜索的优化（生成式引擎可见性）已成独立子领域
- **Agent 就绪度（agent readiness）**：Lighthouse Agentic Browsing、WebMCP、llms.txt —— 专为「让爬虫/Agent 能读懂你的站点」优化
- **9 个可选扩展接实时数据**：DataForSEO、Firecrawl、Ahrefs、Matomo
- **报表输出**：PDF / Excel 报告交付
- **全语种覆盖**：本地 SEO、跨境电商（international SEO）、电商站点

- 站点 SEO 审计与整改清单生成
- AI 搜索时代（GEO/AEO）的可见性优化
- 营销团队把重复性 SEO 工作交给 coding agent 跑
- 用 Agent Skills 机制做垂直领域能力封装的范本

## 为什么值得关注
- **它是「垂直领域专家流程打包成 Skill」的教科书样本。** 与本 catalog 已收录的 cloudflare/security-audit-skill（安全审计流水线）同构：把行业专家的隐性知识（检查项、判定标准、产出格式）显式化成 agent 可执行的技能与子代理，**让非专家也能拿到专家级的产出**。
- **「Agent 就绪度」这一节是全场最值得抄的判断。** llms.txt、WebMCP、Lighthouse Agentic Browsing——这些不是传统 SEO 概念，而是**为「LLM 爬虫能不能正确理解你的站点」重新定义的可读性指标**。SEO 的对象正在从「搜索引擎爬虫」扩展到「Agent 爬虫」，这个项目比大多数还在做 meta tag 的 SEO 工具早看到了两年。
- **10 月仍在 +197/天、51 天涨了近 3,000 星**，在技能包赛道里属于头部。
