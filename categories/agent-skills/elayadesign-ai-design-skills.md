## 一句话
给 AI 编码工具用的「设计 skill 集」——每个 skill 就是一个独立文件夹的 Markdown 规则文件，喂给 Claude Code / Cursor / Codex / Windsurf 就能把「AI 味」设计换成有方法论的设计。

## 核心能力
- **零依赖分发**：skill 就是 `SKILL.md` / rules 文件，不装任何包、不跑任何进程——`cp` 到 `.claude/skills/`、`.cursor/rules/`、`AGENTS.md`、`.windsurfrules` 即可
- **一个 skill 一整套流程**：`landing-page-design` 覆盖 intake 提问 → 页面结构 → 转化文案 → 完整视觉系统（字体 / 间距 / 圆角 / 动效），不是单点提示词
- **设计值集中一处**：每个 skill 底部单独一节写设计值（字体、颜色、间距、动效），改这一处整份 skill 跟着变——这是 skill 少见的「参数化」写法
- **跨 harness 通用**：Claude Code / Cursor / Codex / Windsurf / Cline / Claude.ai 都能吃，同一个文件格式
- **姊妹仓库** `elayadesign/redesign-skill` 专门做「改已有站点」，因为它比这个集更早存在，所以独立成仓

## 为什么值得关注
- **今日涨幅全场第一（+1,395）**，而仓库**只有 5 个 open issues**——9.3 千星配 5 个 issue，说明内容型项目的维护负担极低、但 star 涨得极快。
- **立项不到 3 个月（2026-07-29）**就冲到 9.3 千星，是「设计 skill」赛道里最新也最猛的一个。
- 它的设计哲学跟已归档的 `Nutlope/hallmark`（反 AI-slop 设计 skill）完全一致，但走的是另一条路：hallmark 是**约束**（禁紫渐变、禁圆角卡片），它是**方法论**（该怎么从 intake 走到视觉系统）。**约束防下限，方法论抬上限**——两者可以叠加使用。
- 与本库已收录的 `alchaincyf/huashu-design` 形成第三种范式：huashu-design 是**资产库**（84 种带样张风格库 + 外观账本 + 交付物），它是**流程库**。三种范式正在拼成一个完整的设计 skill 生态。

## ⚠️ 局限
- **仓库无描述、无 topics**，主语言字段为空——GitHub API 侧信息很薄，判断质量只能靠读 SKILL.md 本身。
- **目前只有一个 skill 落地**（`landing-page-design`），README 写着「More on the way」——9.3 千星对应 1 个 skill，**热度里含相当比例的「占位预期」**，后续是否持续补齐是关键观察点。
- **Markdown 规则文件的护栏天然弱**：没有版本化、无法测试、格式变更全靠人工遵守，跟软件工程化的 skill 框架（obra/superpowers 那类）不是一个量级。
- 纯 MIT 授权无任何风险，但**素材/样例授权需另行核对**（与 huashu-design 同类问题）。
