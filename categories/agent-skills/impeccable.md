## 一句话
给 AI 编码工具注入一套统一的**设计语言**，让 agent 产出的界面不再有"模板味"。

## 核心能力
- 把设计规范 / 设计 token 沉淀为 agent 可读的一套语言，供 harness 直接调用
- 让 Claude Code / Codex 等工具在生成前端时遵循统一视觉标准，而非每次从零描述
- 可定制品牌风格，前期投入一次、后续所有产出受益

## 适用场景
- 用 agent 批量产出前端 / UI，且要求稳定的视觉质量
- 不想每轮对话都重复交代设计标准（配色 / 间距 / 层级 / 交互）

## 备注
- 定位与 `taste-skill`（审美好品味）相邻，但 impeccable 更偏"设计语言体系化"而非单点审美纠偏
