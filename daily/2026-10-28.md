### 🥇 HKUDS/DeepTutor —— 「让 agent 来驾驶我的 agent」做成了产品级接口

4.59 万星、Apache-2.0、今天 +1,598。真正的看点不是功能多，而是**它把「被别的 agent 调用」当成一等功能来做**，而且做得比大多数号称 agent-native 的项目彻底：

1. **NDJSON 流式协议 + headless 安全**。`--format json` 每行一个事件（`content` / `tool_call` / `tool_result` / `done`），每行带 `session_id`；最狠的是 **`ask_user` 暂停在没有 TTY 时自动空回复而不是挂起**——这一条决定了它能不能真的跑在 CI / 定时任务 / 别的 agent 的循环里。绝大多数「提供 CLI 的 AI 项目」死在这里。
2. **仓库根目录放 `SKILL.md` 当交接文档**。这不是 README 的一部分，是专门写给 agent 读的握手协议，还配了一份 `AGENT_SETUP.md` 安装指南——**上手路径从「读文档」变成「派个 agent 读文档」**。
3. **记忆可检视**。L1 轨迹 / L2 表层摘要 / L3 综合三层，Memory Graph 把 L2 事实连回 L1 证据。个性化辅导最大的争议是「凭什么这么说」，它把证据链摊开给你看——这跟本库已收录的 cloudflare/security-audit-skill 是同一种价值观：**可验证 > 听起来专业**。
4. **多引擎知识库是「不站队」策略**：LlamaIndex / PageIndex / GraphRAG / LightRAG / 自托管 WeKnora / MarginNote 4 / 腾讯 IMA / Kiwix ZIM / Obsidian vault 全部支持。RAG 这两年最大的教训就是**单一检索范式在真实语料上会崩**，所以直接给了九个后端。

⚠️ 关注理由（三条都挺硬）：**① 功能面过载**——单次发版覆盖 LightRAG / WeKnora / MarginNote / Kiwix / Paged Preview / 原生 speech，README 是一整面特性墙，上手路径远比 star 数暗示的复杂；**② 218 个 open issues 对 4.59 万星（0.48%）仍然偏多**，对一个宣称做多用户协作（learner/guardian 账号）的成熟项目，说明边界情况不少；**③ 依赖极重**——Next.js 16 + Python 3.11+ + 多个 RAG 引擎 + 多个 provider，自托管全量部署的坑不少（有 Docker 一键试玩 `ghcr.io/hkuds/deeptutor:latest`，端口 3782）。

## 🔭 简短趋势观察

1. **「给 agent 用的东西」正在分成两条产品路线，而且都不是包装层。** DeepTutor 走的是**接口路线**：NDJSON 协议、headless 安全降级、仓库根目录放 `SKILL.md` 交接文档、专门给 agent 的安装指南；ai-design-skills 走的是**载体路线**：连软件都不做，一份 Markdown 复制到任何 rules 路径就生效。两条路的共同点是**都不再假设「人坐在终端前」**。这跟 2026 年初那波「给网页加个 AI 按钮」完全是两个物种——**现在的目标用户是 agent 本身**。

2. **提示词正在从「技巧」升级为「有版本、有协议、有归属载体的工程制品」。** jailbreaks 的贡献规范里写着「必须标注归属载体（system prompt / `AGENTS.md` / Modelfile / 配置位）」「大改必须升版本号」「不得声称未实测的兼容性」——**这三条合起来就是一份软件包的发布规范**。再加上它 14.8% 的 fork 率和「paste-ready、不给摘要」的硬要求，可以看出提示词正在获得像 npm 包一样的**独立身份**。而同期 SkillSpector 扫的正是 skill 文件、jailbreaks 收的正是提示词文件——**agent 安全的战场已经明确从二进制层移到了指令层**。

3. **「教育 AI」和「设计 AI」两个垂类同时冒头，说明垂直 agent 正在进入第二阶段。** DeepTutor 4.59 万星、14 种语言 README、Apache-2.0、多 RAG 引擎并行、记忆三层可检视——**教育场景需要的不是更强的模型，是可解释、可追溯、不中断的运行时**。而设计侧三个项目（hallmark 约束 / ai-design-skills 流程 / huashu-design 资产）同时在榜。共同的第二阶段特征是：**不再靠「模型更聪明」取胜，而靠「方法论 + 资产 + 交付物」取胜**。谁能把产出物做到「不返工就能用」，谁就吃到下一波增长——这和 2026-10-27 观察到的「价值锚点从 AI 能做移到 AI 能交付」是同一条线，今天只是从通用工具延伸到了垂直领域。
