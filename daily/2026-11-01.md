## 🎯 三大值得关注的仓库（中文点评）

### 🥇 lightpanda-io/browser —— Agent 时代的「引擎平替」，基础设施逻辑最硬

**⭐ 39,403 / 🍴 1,920（fork 率 4.9%）/ AGPL-3.0 / 今日 +929**。今日清单里最「硬」的一个：它不 produce 内容、不做 agent 编排，而是解决 agent 规模化之后**最底层、最普适的成本问题**——每个 agent 都要开浏览器，Chrome headless 一个实例吃几百 MB 内存、冷启动数秒，fleet 一大就是真金白银的税。看点三层：

1. **Zig 从头写引擎**，不是套壳 Chromium：内存和启动速度是数量级改善的叙事，而非 10-20% 的优化叙事。
2. **原生 CDP server 兼容 Playwright/Puppeteer**——迁移成本≈0，这是所有「更快引擎」项目里最难做到的一条：不动开发者的 muscle memory。
3. **形态是典型基础设施**：fork 率仅 4.9%、issues 100——用户多、魔改少、跟着用，比 15% fork 率的工具型项目更接近「水电」的活法。

⚠️ AGPL-3.0 商用嵌入需谨慎；39K 星对 Zig 项目是极高的期望值，浏览器引擎的兼容性长尾（JS API、CSS、反爬对抗）是持久战。

### 🥈 milind-soni/OpenMausBot —— 今日增速第一，「bot + VM」是 computer-use 的开源平权

**⭐ 9,878 / 今日 +1,303（全场第一）/ Apache-2.0**。8 月创建、3 个月近万星。Grok Bot 的开源替代，但真正的差异点是**给 bot 配一台可自主使用的虚拟机**：agent 不再只是「在聊天框里输出」，而是拿到一台能操作的电脑——下载文件、跑脚本、操作 GUI。这与 computer-use 赛道（OpenAI/Anthropic 的闭源能力）形成开源对位。Electron 桌面 + Expo 移动端 + Docker VM 的组合拳，Apache-2.0 对二开友好。⚠️ 617 open issues 说明粗暴增长期，VM 沙箱的安全边界（prompt injection → 主机逃逸）是这个品类最大的达摩克利斯之剑。

### 🥉 Orkas-AI/Orkas —— 「AI 员工」桌面整合，做 harness 的调度层而非又一个 harness

**⭐ 6,838 / 今日 +1,044 / MIT / 仅 7 open issues**。Agent 编排赛道已经严重同质化（openbot、cindy、orca……），Orkas 的卡位聪明：**不自己造 harness，而是把 Claude Code / Codex / OpenCode / OpenClaw / Hermes 当作可调度的「员工」**，Commander 负责把目标拆成 to-do 再分配给 16 个内置专家 + 外挂 harness。local-first、自带模型或自带 key、macOS/Windows 免费应用、MIT——姿态是「桌面 AI 团队的指挥台」。对 OpenClaw 用户尤其值得一看：它是把 OpenClaw 当作编排对象的产品化案例。⚠️ 7 个 issues 对 6.8 千星意味着社区反馈回路尚未形成，插件/connector 生态能否立起来决定它是玩具还是平台。

## 📈 趋势观察

1. **Agent 栈的「垂直行业化」**：Claude-Code-Game-Studios（游戏工作室）、OpenMAIC（课堂）、Orkas（桌面团队）——通用 agent harness 之后，下一波是按行业/场景封装「组织结构 + workflow」的产品，组织架构本身成了 prompt 工程的载体。
2. **Agent 成本基础设施开始爆发**：Lightpanda（浏览器引擎）连续霸榜印证：当 agent 数量上量，单实例的内存/启动成本会被无限放大，底层「减税」项目的星辰大海才刚开。
3. **「自带 VM/computer-use」成为桌面 agent 标配**：OpenMausBot 增速第一说明市场认定——不能操作环境的 agent 只是聊天机器人，能操作环境的才是员工。
