## 最值得关注的 3 个

### 🥇 shadcn/improve —— 把 token 账单按「谁干活」拆开
一句话戳中当下所有 agent 团队的钱包痛点：**最贵的模型只做审计和写计划，便宜的模型照计划改代码**。这不是又一个 agent 框架，而是成本工程的一次范式切分——把「判断力」和「执行力」明码标价成两档模型。6 个月 1.09 万星、只有 18 个 open issues，说明设计足够收敛；但要注意它 9 月 12 日之后就没再推送，热度是社区扩散出来的。**建议动作**：先把它的计划模板拿来看一遍，思路本身比代码值钱，完全可以照搬到自己的 CI 里。

### 🥈 openai/codex-security —— 安全扫描从「找」进化到「证伪 + 修复」
今日只 +52，但它已经在榜上稳住很久了——这种「不靠爆点、每天有人用」的项目通常比爆款更值得跟。它最大的差异点是不止扫漏洞，还强调 **validate（证明真可利用）+ fix（直接给补丁）**，本质上是用 agent 把误报率压下来。CLI 一行接进 CI、SDK 自写批处理，两条路都通；Apache-2.0 + 官方文档站，商业接入没有协议负担。搭配已经收录的 Cloudflare security-audit-skill、NVIDIA SkillSpector，正好凑齐「审 skill → 审代码 → 修代码」的 agent 安全三件套。

### 🥉 GoogleChrome/modern-web-guidance-src —— 治 AI 写前端的「过时病」
仓库连描述和 topics 都没填，却是今天最实用的一条。AI 生成前端代码的死穴不是不会写，是**写出五年前的写法**。这是 Chrome 团队官方维护的「现代 Web 用法」源仓库，Apache-2.0，可以安全抓取、索引、蒸馏进自有知识库，当成 agent 的规范输入或 RAG 语料。361 个 open issues + 8.1% fork 率说明它在被认真纠错，不是死文档。

### 补充：TheAlgorithms/Java —— 十年老树，换了新用途
2016 年至今 6.7 万星、32.1% fork 率、仅 29 个 open issues。今天它的价值早已不是「学算法」，而是**训练与评测语料**：单文件单算法、结构规整、注释规范，是代码模型微调/基准的高质量来源。MIT，直接 fork 进企业内训仓库即可。

## 趋势观察

1. **「双档模型」开始成为产品语言。** 今天的头名不是能力更强的 agent，而是把成本分配写进 slogan 的工具。行业从「用最强模型」转向「在对的环节用对的模型」，这与 headroom、caveman 这条「给 agent 省 token」的路线是同一条曲线的两端——一端省输入，一端省执行。
2. **官方仓库持续吃掉第三方生态位。** OpenAI 出安全 CLI、Chrome 出现代 Web 指引，标准制定者直接下沉做工具。对开发者是好消息（协议干净、文档齐全），对同赛道的创业项目则是挤压——留给第三方的空间正在变窄。
3. **榜单结构「冷热分化」明显。** 今日新收录 4 条，最高单日增量 +361，与近期动辄 +1,200/+2,700 的 AI skill 爆款形成鲜明对比。爆点集中在 agent skill 类，而工程基础设施类项目靠**日拱一卒**的稳态回流上榜——后者往往是更好的长期跟踪对象。
4. **经典项目重新回流。** TheAlgorithms/Java 这类 2016 年的老仓库出现在今日 Trending，说明市场在 AI 代码生成的噪声之外，重新对「结构化的确定性知识」产生需求。
