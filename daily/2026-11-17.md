## 最值得关注的 3 个仓库

### 1. kajisho5/ffmpeg-skill —— 把「视频剪辑」变成 agent 的一份可执行契约
今日增速第一（+367）。它没有重写 FFmpeg，而是给 42 个 FFmpeg 能力套了一层**机器可读契约 + MCP server**：agent 不是靠猜命令行参数，而是按 schema 调用"剪一段/加字幕/改构图/调响度/按平台导出"这些语义动作。这是 agent 工具链里最被低估的一层——**把不可靠的字符串拼接变成可校验的接口**。全部本地跑、无需 API Key、无云端上传，对"素材敏感 + 不想付费"的场景几乎零阻力。两个月前才创建、今天已 6.7K 星，说明这个需求一直存在只是没人正经做。

### 2. google-research/paper-orchestra —— 论文写作流水线的 multi-agent 打样
Google Research 出品、Apache-2.0、今日 +313。多 agent 分工完成「调研 → 大纲 → 写作 → 图表 → 修订」的 AI 研究论文全流程，带官方项目页与实验说明。fork 率 15.7%（今日新收录最高）说明它不是看一眼就走的那类仓库——**真有人在拆开改自己领域的流水线**。⚠️ 学术场景的诚信红线自己把握：能起草 ≠ 能署名，用于综述框架、文献组织、初稿骨架是它的正确用法。

### 3. getarcaneapp/arcane —— Docker 管理的「该有的样子」，长期价值大于今日热度
今日只 +46 看着不炸，但 8.7K 星 + 仅 11 个 open issues + 18 个月持续维护，是今天清单里**工程质量最干净**的一个。它要解决的是 Docker Desktop 那条路的老问题：容器/镜像/Compose stack 的可视化管理 + 自托管，Go 写的单二进制，只花不到 Docker Desktop 一年授权费的钱。和 Coolify/Dokploy 的差异在于它偏"管已有 Docker 环境"而不是"替你部署"。今日热度低恰恰是优点——不是被热搜带起来的项目。

## 趋势观察

1. **Agent skill 已成独立品类，且开始「啃专业器件」。** 今天 10 条里有 3 条是 skill/agent 工具（ffmpeg-skill、last30days-skill、paper-orchestra），关键词都是同一个套路：**给 agent 一套有 schema 的专业能力**。skill 竞争从"提示词技巧"转向"接口设计 + 契约稳定性"。
2. **本地优先（local-first）持续吃香。** ffmpeg-skill「无云、无 API Key」、arcane 自托管、jiangshan-map 静态站直接跑，读者对「我能自己跑、数据不出门」的偏好在这轮 Trending 里是明确主线，对标的是上一轮 SaaS 全线涨价/改授权。
3. **人文学科工具开始稳定上榜。** 江山时序（+288、GPL-3.0、18 朝代 198 张疆域快照）不是玩具 demo，数字人文 + GIS + 古典诗词路线的工程量摆在那儿。中文社区的"文化类开源"今年出圈频率明显上升。
4. **老框架依然有日常流量。** Svelte 88.9K 星 +115，2016 年立项的框架还在榜上——但注意它 1,313 个 open issues 的体量，高频上榜更多是版本节奏带来的关注，不是新采纳拐点。
5. **增速与质量不同步。** 今日增速榜前二（ffmpeg-skill +367、paper-orchestra +313）都是两个月内新仓；而 fork 率最高的 paper-orchestra 与 jiangshan-map（15.7% / 11.8%）说明"能被改造"比"被点赞"更有信号价值。看 Trending 时，**fork 率和 open issues 数比 stars 更值得先看。**
