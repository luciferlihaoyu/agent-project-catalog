## 最值得关注的 3 个仓库

### 1. dream-num/univer — AI Office SDK，agent 的「办公操作面」终于成熟
+495 是今天全场增速第一梯队，2.4 万星体量还能有这么陡的日增，说明「AI office」叙事开始兑现。它的本质是把 Excel/Doc/PDF 的编辑、公式计算、多人协作做成可嵌入 SDK，让任何 SaaS 不用从零造 office；真正踩中风口的是描述里那句 "for people and AI agents"——表格和文档天然是 agent 最结构化的操作面，agent 读写 Excel 需要的不是又一个文件解析库，而是带计算引擎和协作状态的真实 office 内核。在本 catalog 里它和 supabase（Postgres 应用底座）互补：一个管数据层、一个管办公面。Apache-2.0 + 165 issues 对 2.4 万星非常干净，做 agent 操作文档/表格的产品可以直接上手。

### 2. Tencent/LoopForge — coding-agent 交付环节的「审批门」
腾讯出品的 coding-agent 交付编排器：把 CodeBuddy/Codex/Claude Code 这类 agent 的产出装进「脚本 + 人工审批门」的自托管工作流。关注它的理由是 fork 率 23.2%——今日新收录里最高，真拿去改真用的人比例极高；创建仅 3 个半月即上 Trending，最后推送就是今天。它和已收录的 plannotator（批注决策台）、JetBrains thinkrail（agent 宿主 IDE）同属「人在环」赛道，但切的是交付环节：agent 写完代码不是终点，过审批门才算交付。多 agent 混用的团队（codex/claude 并行场景）可以直接参考它的 gate 设计。⚠️ 协议 NOASSERTION，商用前确认。

### 3. ag-ui-protocol/ag-ui — agent 前端交互的协议层，看生态位不看日增
今天 +9 增速不显眼，但 protocol 类项目的价值在采用广度而非热度曲线：17,369 星 / MIT，本 catalog 已收录的 CopilotKit/OpenBot 明确写着「接任意 AG-UI agent」——等于生态里已有项目把它当日程依赖。AG-UI 定义的是 agent 事件流与前端状态的双向协议，是「agent 走向前端」这一层的事实标准候选。593 open issues 偏多属于规范类项目常态（大量是集成咨询而非缺陷），做 agent 前端的人绕不开它。
